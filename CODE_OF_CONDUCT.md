# Code of Conduct

ReMCP is built for people who want to collaborate on secure, reliable computer automation. We expect project spaces to stay useful, respectful, and safe for contributors and users.

## Expected behavior

- Be respectful and constructive, especially when reviewing bugs, security concerns, or competing technical approaches.
- Critique code and ideas rather than people.
- Respect privacy. Do not post credentials, private logs, personal data, or other people's machine contents.
- Keep reports reproducible and relevant to the project.
- Assume good faith while still treating security boundaries and untrusted content seriously.

## Unacceptable behavior

Harassment, discrimination, threats, targeted abuse, doxxing, deliberate disclosure of private information, or using project infrastructure to facilitate abuse are not acceptable.

## Scope

This code applies to ReMCP repositories, issues, pull requests, release discussions, support channels, and other spaces where someone is representing the project.

## Reporting and enforcement

Report conduct concerns privately to support@remcp.site or through https://remcp.site/support. Do not open a public issue if the report contains sensitive personal information.

Maintainers may edit or remove content, close or lock threads, restrict participation, or take other proportionate action needed to protect the community and the project. Reports will be reviewed with discretion and shared only as needed to investigate and respond.

For product security vulnerabilities, use the private vulnerability-reporting path described in SECURITY.md instead of the conduct channel.
